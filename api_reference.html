1. What this is

Public marketing catalog for Japanese / western food ingredients distributed in Indonesia. NONE. No login, no API key, no session token, no cookies are required for any GET described here.

Safety: All access in this project is read-only GET. Inquiry/contact POST endpoints exist on the site and are intentionally NOT used.

Inferred stack: Laravel (XSRF-TOKEN / masuya_session cookies, Blade templates), jQuery 1.11 + 3.6, server-rendered HTML.. There is no public JSON product API; data is extracted from server-rendered HTML.

Query parameters

ParameterMeaning
keywordFree text product search.
catBase64-encoded category id, e.g. MTg= (18 = Dairy). URL-encode '=' as %3D.
subBase64-encoded subcategory id, e.g. NDc= (47 = Cheese). Some values have no padding, e.g. MTQz (143).
brandBase64-encoded brand id, comma-separated for multiple brands, e.g. MTMz (133 = Yamamotoyama).
page1-based page number.
sortasc | desc | alphabet-asc | alphabet-desc.

ID encoding

base64 of the decimal database id, sometimes with '=' padding and sometimes without. Pass the encoded value through unchanged; the client exposes a decoded numeric id only for readability.

MTg= -> 18 (Dairy); NDc= -> 47 (Cheese); Mzc= -> 37 (Groceries); MTMz -> 133 (Yamamotoyama); MTQz -> 143 (Seaweed)

4. Published vs missing data

Available per product

  • name
  • brand
  • slug / URL
  • image URL
  • item code (derived from image filename or slug)
  • description
  • packaging (carton configuration, e.g. 12X1000ML)
  • storage (CHILLER / FROZEN / DRY / CHILLER AC)
  • packing size (e.g. 1000 ml, 200 gr)
  • category and subcategory membership

Not published — do not invent

  • price — No prices anywhere. The site is inquiry-based; every product has a 'MAKE A INQUIRY' CTA.
  • stock — No availability or stock counts.
  • ingredients — No composition / ingredient list.
  • halal — No halal certificate field.
  • nutrition — No nutritional information.
  • origin — No country-of-origin field (brand names often imply it, but this is not confirmed data).
  • minimum_order — No MOQ or order quantity.
  • consequence — Price comparisons, ingredient-level substitution decisions and quality guarantees cannot be made from public data alone. Request specs and samples from a sales representative.

All tools are read-only. Results include typed structuredContent; oversized results are truncated as valid JSON with a _truncated notice. Search hits carry match_quality (strong / possible / weak) and masuya_match_names reports likely_absent_from_catalog, so a loose token hit is never mistaken for a real product.

Compared with the Sukanda MCP

Sukanda: Authenticated buyer API (JWT), prices, stock, purchase history, order data, ingredient composition.
Masuya: Public marketing catalog, no login, no prices, no stock, no order data, no ingredient composition.
Usage: Use Sukanda for buy/pricing decisions and Masuya for range discovery and alternative shortlists; never compare prices between them from public data.

6. Politeness & verification

Observed: No rate limit or 429 was encountered while crawling 62 listing pages plus category pages.

Client policy: 0.12 s minimum interval between requests, 2 retries, 25 s timeout, in-memory 10-minute HTTP cache, 7-day detail cache, and a bundled catalog_index.json snapshot so ordinary questions need zero new requests.

Scope: Only public GET requests to the pages listed above. No POST, no forms, no reCAPTCHA, no account data, no credentials.
